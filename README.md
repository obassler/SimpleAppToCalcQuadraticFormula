# Quadratic Equation Calculator

Android app that solves quadratic equations *ax² + bx + c = 0* – enter the coefficients and get the real roots (two, one, or none, based on the discriminant).

## Running

Open the project in Android Studio and run the `app` configuration on an emulator or device.
